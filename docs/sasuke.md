# サスケのボドゲ棚 — 運用メモ

毎週土曜20:00 JST に「サスケのボドゲ棚」を自動投稿する枠の運用知識。
コードやコミット履歴からは読み取れない「決めごと」だけをここに残す。
（出典: MITAKECATSセッションからの組み込み依頼 INTEGRATION.md を要約。素材一式は
配置済みのため元フォルダ sasuke_module は破棄した。）

## 仕組みの在りか

- 画像生成: `sasuke/make_card.py`（1080×1350 JPEG・自己完結）
- 投稿本体: `sasuke/run_sasuke.py`（未投稿の最小volを取る→カード生成→
  [カード, 締めロゴ]の2枚カルーセルを投稿→state記録）
- 投稿キュー: `sasuke/queue.json`（vol / game / serif / caption）
- ゲーム一覧: `sasuke/games.csv`（ゲーム名 / プレイ人数 / プレイ時間 / 対象年齢 / 発売年）
- 素材: `sasuke/assets/`（sasuke_face.png / mitakecats_logo.png / closing.jpg）
- ワークフロー: `.github/workflows/sasuke-weekly.yml`（cron `0 11 * * 6`＝土20:00 JST）
- 投稿済み管理: `state/sasuke_posted.json`（自動生成・自動コミット）
- トークンは新設せず、みるくと同じ `IG_ACCESS_TOKEN` を自己延長して使い回す。

## vol の採番

- vol.01〜04 は3号さんが Instagram アプリの予約投稿で手動セット済みの想定。
- 自動投稿のキューは **vol.05 から**始まる（現在 vol.05〜16 の12週分）。

## キャプションの扱い

- `queue.json` の `caption` は **無編集でそのまま投稿**する。サスケの口調ルールが
  焼き込んであるため、こちらで手を入れない。
- 将来こちら側でキャプションを書く場合の口調ルール:
  - 一人称は「僕」
  - 語尾に控えめな「にゃ」（文末中心。ナ行を稀に「にゃ」化する程度）
  - 冷静な解説役。誇張しない
  - 最後は必ず定型文（MITAKECATSの注記）とハッシュタグで締める
- ゲームのルール記述は12本とも裏取り済み。変更するとルール誤記のリスクがあるので触らない。
- 場所の呼称は「プレイルーム」。**「蔵」という場所はみたけに実在しない**ので使わない。
