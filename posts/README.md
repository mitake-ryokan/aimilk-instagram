# 予約箱（posts/）

臨時の投稿（お知らせ・季節・求人・相談など）を、決めた時刻に Instagram へ出すための箱です。
サスケのボドゲ棚のような「毎週決まった形」の投稿は、ここではなく `sasuke/` が担当します。

## 流れ

1. `posts/` の下に1本ぶんのフォルダを作って、プルリクエストを出す
2. プルリクエストに付く**緑のチェック**（中身の点検）を確かめる
3. 3号さんがスマホの GitHub アプリで画像と文章を見て、**マージ**する ← これが承認
4. 決めた時刻を過ぎた最初の見回り（30分おき）で、Instagram に出る
5. 出たら LINE に知らせが届く（LINE の設定があるとき）

**マージしていないものは出ません。** 決まった時間に動く仕組みは main しか見ないからです。

## 1本ぶんのフォルダ

フォルダ名は `日付_名前`（例：`2026-10-10_kagami`）。

```
posts/2026-10-10_kagami/
  post.json      いつ出すか
  caption.txt    キャプション全文（そのまま投稿される）
  1.jpg          画像。1枚なら単体投稿
  2.jpg          2枚以上ならカルーセル（10枚まで）。並びはファイル名の数字の順
```

post.json

```json
{
  "publish_at": "2026-10-10T20:00:00+09:00",
  "title": "鏡のご相談"
}
```

- `publish_at` は**日本時間なら末尾に `+09:00`** を付ける
- `title` は自分用のメモ。投稿には出ない
- 画像は **JPEG**。縦長は 4:5（1080x1350）まで
- ハッシュタグは **5個まで**（みたけの決まり）

## 安全装置

| こんなとき | どうなる |
| :-- | :-- |
| マージしていない | 出ない |
| 一度出した | `published.json` が付いて、二度と出ない |
| 予定時刻を24時間以上過ぎていた | 出さずに `expired.json` を付ける（古いお知らせが突然出るのを防ぐ） |
| 投稿に失敗した | `failed.json` を付けて止まる。自動ではやり直さない |

失敗したものをもう一度出したいときは、直したうえで `failed.json` を消すプルリクエストを出す。

## 公開リポジトリであることに注意

画像を公開URLで Instagram に渡すため、このリポジトリは公開されています。
**予約箱に入れた画像と文章は、マージ前でも GitHub 上では誰でも見られます。**
お客様の顔が写った写真や、まだ出せない情報は入れないこと。
