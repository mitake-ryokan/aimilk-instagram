# AIみるく Instagram 自動投稿

温泉旅館みたけ（箱根・仙石原）の看板猫「AIみるく」が、
箱根町・仙石原のイベント情報を毎週Instagramに投稿するシステム。

## セットアップ

`docs/セットアップ手順.md` を上から順にどうぞ。

## 使い方（動き出したあと）

Googleスプレッドシート「AIみるく イベントマスタ」の「掲載可否」列を
`○` にしたイベントだけが投稿されます。週1回、5分見るだけです。

## 中身

| ファイル | 役割 |
|---|---|
| `src/run_weekly.py` | 全体の流れ。ここを読めば何をやっているか分かる |
| `src/config.py` | 設定の読み取り口 |
| `src/google_client.py` | スプレッドシートとDriveから読む |
| `src/instagram.py` | Instagramへ投稿する・トークンを延長する |
| `src/builder.py` | 画像とキャプションを組み立てる入口 |
| `src/layouts_v.py` | 投稿画像のデザイン（A案：全面写真＋下部カード） |
| `src/motifs.py` | 季節モチーフのイラスト（写真がないとき用） |
| `.github/workflows/weekly-post.yml` | 毎週木曜18時に自動実行する設定 |

## 大事なルール

- キャラクターの表記は必ず **AIみるく**。「みるく」「ミルク」単独では呼ばない
- 免責文はコードに埋め込んである。データ側からは消せない（入れ忘れ防止）
- 掲載可否が `○` のイベントだけ投稿される（誤情報を出さないための人の関門）
- `○` が2件未満の週は投稿しない
